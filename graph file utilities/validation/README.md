# pnaut-graph-utilities/validation
This folder contains a pythons script, *visualize_miyazaki.py* that is useful
in validating the Miyazaki graph generator provide is accurate.  This script
takes two inputs, the $k$ value from the M-$k$ designation, and an input graph
filename.  This is not a highly sophisticated script, make sure to get the $k$
value and graph size to match, or it won't run properly. 

The output of this script is a .png file that is a graphical representation
of the input graph, as generated by the *NetworkX* and *matplotlib* Python libraries.
The only modification done from a simple rendering, is providing vertex locations
to *NetworkX* so the layout of the vertices matches the standard layout used
to display a Miyazaki graph.  No modification is done to any edges.

## Files
Three samples are provided in this repository, M-1.g6, M-2.g6, and M-3.g6 graphs
have been provided, along with the .png results of running them in the visualization
script.  A .png file is provided that demonstrates what the graphs should look
like.
